Atlas Household — kiosk design reference

The visual language of the wall-mounted kitchen iPad, on one static page. Hardcoded placeholder data. The shipped implementation lives in apps/web/src/; if the two disagree, the app is right.

Reconstructed from the written design brief and kept in step with what apps/web ships. Names are the placeholders from apps/api/seed.example.json.

Screen 1 — family

Five tiles, one row. Ring = today's done / total. Green means finished and nothing else in the grid is allowed to be green, so a member whose own colour is green never reads as done. The dependent shows a face and a name only: no count, no ring, not a button.

Screen 2 — one person's day

Progress bar mirrors the ring. A finished row turns green, fills its check, and mutes the title. The toast confirms the tap and offers Undo, wired to the existing uncomplete endpoint.

Type

Nunito from the Google Fonts CDN, loaded non-render-blocking (media="print" then promoted on load) so an unreachable CDN costs the kiosk its typeface and never its first paint. The fallback leads with ui-rounded, which resolves to SF Pro Rounded on iPadOS — the nearest native match, so the board keeps its rounded character offline.

Deliberately not built

These appeared in the original mock. Each is excluded because shipping it would have the board state something false to the family. Do not reinstate any of them from this reference.

  • Due times (“By 9:30 PM”) — chore_instances has due_on, a date. There is no cutoff-time column, so any time shown would be invented.
  • Escalation copy (“someone gets a nudge if it's missed”) — no notification service exists. A promise the system cannot keep is the fastest way to lose the kids' trust in the board.
  • The Calendar tab — its history was a seeded random number. Hidden entirely until a real history endpoint exists: not shipped with today's data only, and not shipped empty.
  • The subtasks / steps expander — there is no chore_subtask_instances table.
  • A task on the dependent, or a tappable dependent tile — the API rejects a completion by a dependent (routes.py, 400). The tile shows a face and a name, no count, and is not a button.
  • A checkbox on the 8:00 PM strip — the strip is kept, but it is a static schedule display. No chore_instance backs it, so there is nothing to complete.
